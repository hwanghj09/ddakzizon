# 게임 픽셀 아트

PC 웹 전용 게임의 캐릭터·배경·환경 소품을 같은 픽셀 스타일로 표시한다.

- 캐릭터 18종의 대기·걷기 A/B·내려치기 72장은 **32×32 격자에 직접 그린다**. 프레임마다 최대 16색과 투명도 0/255를 사용한다.
- 배경 16종 / 16개 PNG: **240×160**, 배경마다 최대 48색, 불투명. 운동장, 집, 골목, 광장, 주민센터 앞, 로비, 학교 앞, 교실, 정자, 시 체육관, 도 압축 경기장, 전국 경기장, 대륙 사막, 세계 야경, 행성 기지, 마을 대회 광장.
- 소품 17종 / 17개 PNG: 실제 **32×32**, 투명 배경. 침대, 식탁, 표적, 문, 게시판, 벤치, 우편함, 화분, 자전거, 가방, 접수대, 가게, 교문, 압축기, 정류장 표지, 대전 매트, 가족사진.
- 딱지 아이템 184개도 실제 32×32 RGBA이며 별도의 `assets/sprites/ttakji`를 사용한다.

## 긴 배경과 카메라

`panoramas/`의 15종은 한 화면을 늘린 그림이 아니라, 각 구역의 실제 폭에 대응하는 연속 파노라마다. 원본은 `sources/panorama-*.png`에 보존하며 `scripts/draw-panoramas.cjs`로 재생성한다. 런타임에서는 픽셀 4배를 유지하고, 배경·바닥·소품·캐릭터 모두 `-round(camera)`만큼 이동한다. 학교·마을·시·도·전국과 대륙·세계·행성 허브에서 카메라가 주인공을 따라가며 양쪽 끝에서 멈춘다. 기존 16종 배경은 교실·타이틀·전투 같은 고정 장면에서 사용한다.

## 게임 적용

`manifest.json`과 `art-manifest.js`는 같은 경로·크기·기준점을 기록한다. `art.js`는 모든 PNG를 미리 불러오고 캔버스 이미지 보간을 끈다.

32×32 캐릭터 프레임의 발 기준점은 `[16,30]`이다. 화면에서는 보간 없이 기존 캐릭터 표시 크기를 유지한다. 초상화는 대기 프레임의 `(4,0)`부터 24×24 영역을 잘라 CSS `image-rendering: pixelated`로 표시한다. 대회 상대도 전투 역할에 따라 공격 프레임을 사용한다.

배경은 4배로 확대하며 비율을 유지한다. 장면마다 `horizon`을 실제 바닥 위치에 맞춰 정렬한다. 전투·집·탐험처럼 카메라 높이가 달라져도 마지막 지면 안쪽의 작은 스트립을 반복해 화면 아래에 빈 영역이 생기지 않게 한다. 시·도·전국은 각각 별도 배경을 사용한다. 대륙·세계·행성은 허브와 전투장 모두 새 배경을 사용한다. 기존 마을·시·도·전국의 이전 허브 렌더 경로도 새 배경으로 연결했다.

소품의 알파 경계로 실제 그림 부분만 배치하므로 상호작용 좌표와 이름표가 유지된다. 이미지가 로드되지 않으면 기존 도형 장면을 사용하고, 캐릭터의 걷기/공격 프레임이 실패하면 같은 캐릭터의 대기를 사용한다.

## 재생성

- `npm run art:characters`는 `scripts/draw-characters.cjs`의 픽셀 도안과 팔레트에서 캐릭터 PNG 72장과 두 manifest를 갱신한다. Node 표준 라이브러리만 필요하다.
- `npm run art:scenes`: `scripts/draw-scenes.cjs`로 16개 배경과 직접 그린 17개 소품 및 두 manifest 갱신. 배경 내보내기에 ImageMagick이 필요하다.
- 배경의 새 ImageGen 아틀라스는 `sources/world-atlas.png`에 포함한다. 4×4 순서는 생성 스크립트의 `names`와 같다. 원래 생성 결과를 최근접 방식으로 960×640, 128색으로 정규화했고 각 240×160 셀을 개별 48색 RGBA PNG로 내보낸다. 기존 손그림 배경의 축소본은 사용하지 않는다.
- `npm run art:panoramas`: 실제 맵 너비와 동일한 파노라마 15개 및 manifest 갱신.
- `npm run art:items`: 딱지 184개를 32×32 RGBA, 최대 32색으로 정규화.
- `python3 scripts/export-art.py`: 아트 생성기를 순서대로 실행하는 이전 명령 호환 진입점. 외부 원화 파일은 필요 없다.
- 서버 실행 후 `node scripts/preview-characters.cjs`, `node scripts/preview-scenes.cjs`: 실제 런타임 PNG의 비교표 촬영.

## 검증

`npm run check`, `npm test`, 별도 `npm start` 실행 후 `npm run test:art`, `npm run test:minimum`, `node tests/exploration.browser.cjs`, `node tests/menus.browser.cjs`.

배경 검사는 전체 16개 실제 장면과 대륙·세계·행성 허브/전투장, 키보드 시설 진입, 4가지 카메라 높이 × 16개 배경의 지면 채움, 1024×600 메뉴를 확인한다. 단위 검사는 규격·팔레트·투명도·경계 및 두 manifest의 일치를 검증한다.

`npm run test:scrolling`은 실제 키보드 이동·일시정지·저장 복귀와 파노라마 15개의 정확한 64px 이동/맵 끝 빈 공간을 검사한다. `npm run test:story`는 아쉬운 첫 패배·집으로의 페이드·아빠 대화 중 저장 복원·첫 강화 수치를 검증한다.
