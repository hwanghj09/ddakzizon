# 게임 아트 — 16×16 캐릭터

캐릭터 PNG는 **실제 16×16픽셀**이다. 큰 원화를 줄인 이미지가 아니라 최종 픽셀 격자에 새로 그렸다. PC 웹 전용 게임에서 사용한다.

- 배경 9개: 교실, 운동장 정자, 집, 골목, 광장, 주민센터 앞, 주민센터 로비, 학교 앞, 운동장.
- 캐릭터 12종 / **48개 파일**: 주인공, 민수, 대장, 챔피언, 친구, 앞집 아저씨, 탈모 아저씨, 박자왕, 접기 장인, 세계 챔피언, 외계인, 행성 챔피언. 모두 대기/걷기 A/걷기 B/내려치기 4동작.
- 소품 17개: 침대, 식탁, 표적, 문, 게시판, 벤치, 우편함, 화분, 자전거, 가방, 접수대, 가게, 교문, 압축기, 정류장, 대전 매트, 가족사진.
- 캐릭터와 소품은 RGBA 투명 배경, 배경 그림은 불투명 PNG. 캐릭터는 최대 16색, 알파 0 또는 255만 사용한다.

캐릭터의 색상·모자·머리 모양·안경·더듬이를 유지해 픽셀 아트로 다시 그렸다. 배경 9개와 소품 17개는 기존 256×256 원화다. 딱지 184개 이미지도 기존 규격을 사용한다.

`manifest.json`과 `art-manifest.js`는 같은 이미지 경로·알파 경계를 기록한다. 캐릭터 크기는 `[16,16]`, 발 기준점은 모든 동작에서 **`[8,15]`**다. 런타임은 정수 배율로 확대하고 보간을 끄므로 이동·공격·좌우 반전 시 크기와 발 위치가 유지된다. 초상화는 대기 그림의 `(2,0)`부터 12×12 영역을 잘라 CSS `image-rendering: pixelated`로 확대한다. 모든 대회 상대는 기존 외형 분류에 맞는 픽셀 캐릭터와 공격 프레임을 사용한다.

`art.js`가 이미지를 미리 불러오고 기존 월드 렌더러와 연결한다. 오프닝 교실, 주요 탐험 구역과 학교/연습/주민센터 경기 장면에 그림을 적용한다. 짧은 여정의 학교는 정자 배경을 사용한다. 시·도·전국 탐험과 경기장은 로비 배경을 공유한다. 대륙·세계·행성은 기존 배경 렌더러와 새 픽셀 캐릭터를 사용한다. 캐릭터·소품·배경 확대에 이미지 보간을 사용하지 않는다. 걷기/공격 이미지 로딩이 실패하면 같은 캐릭터의 대기 이미지로 복귀하며, 배경이 실패하면 기존 월드 렌더러를 사용한다.

캐릭터 재생성: **`npm run art:characters`**. `scripts/draw-characters.cjs`의 픽셀 도안과 팔레트가 원본이며 Node 표준 라이브러리만 필요하다. PNG 48장과 두 manifest를 함께 갱신한다.

배경/소품 재생성: `scripts/export-art.py sources.json`. ImageMagick으로 기존 원화를 내보낸 다음 픽셀 캐릭터 생성기를 호출하므로 캐릭터가 예전 256×256 그림으로 되돌아가지 않는다.

검증: `npm run check`, `npm test`, 서버 실행 후 `npm run test:art`, `npm run test:minimum`, `node tests/menus.browser.cjs`, `node tests/sprites.browser.cjs`. [전체 캐릭터 비교표](./characters-preview.png)는 서버 실행 후 `node scripts/preview-characters.cjs`로 다시 촬영할 수 있다.
