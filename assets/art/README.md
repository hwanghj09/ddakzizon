# 게임 일러스트

모든 적용 PNG는 **256×256픽셀**이다. PC 웹 전용 게임에서 사용한다.

- 배경 7개: 집, 골목, 광장, 주민센터 앞, 주민센터 로비, 학교 앞, 운동장.
- 캐릭터 12종 / 18개 파일: 주인공·민수 각각 대기/걷기 A/걷기 B/내려치기, 조연 10종 대기.
- 소품 17개: 침대, 식탁, 표적, 문, 게시판, 벤치, 우편함, 화분, 자전거, 가방, 접수대, 가게, 교문, 압축기, 정류장, 대전 매트, 가족사진.
- 캐릭터와 소품은 RGBA 투명 배경, 배경 그림은 불투명 PNG.

ImageGen으로 제작한 손그림 원화를 개별 파일로 분리하고 비율을 유지해 축소했다. 큰 제작용 원화는 게임에 포함하지 않는다. 기존 딱지 184개 이미지는 변경하지 않는다.

`manifest.json`은 이미지 경로, 실제 그림의 알파 경계, 발 기준점 `(128,240)`을 기록한다. 주인공과 민수의 네 동작은 동일한 축소율을 사용하므로 공격 자세가 낮아져도 몸 크기가 달라지지 않는다. 캐릭터를 좌우로 뒤집을 때도 같은 발 기준점을 사용한다. 초상화는 캐릭터의 대기 그림에서 런타임에 잘라 사용한다.

`art.js`가 이미지를 미리 불러오고 기존 월드 렌더러와 연결한다. 주요 탐험 구역과 학교/연습/주민센터 경기 장면에 그림을 적용한다. 시·도·전국 탐험과 경기장은 로비 배경을 공유한다. 대륙·세계·행성 배경은 기존 렌더링을 유지하며 새 캐릭터와 대전 매트를 사용한다. 배경은 비율을 유지해 PC 게임 화면에 맞춰 일부를 잘라 표시한다. 256픽셀 원본이므로 큰 창에서는 배경이 부드럽게 확대된다.

`scripts/export-art.py sources.json`으로 ImageMagick 기반 분리/축소/256 캔버스 출력을 재현할 수 있다. 원본 파일 경로는 인자로 제공하며 런타임에는 필요 없다. 검증: 서버 실행 후 `npm run test:art`, `npm run test:minimum`.
