# 손그림 UI 소재

UI용 SVG를 직접 작성했습니다. 외부 이미지 주소나 글자가 들어 있지 않아, 게임의 실제 텍스트·버튼·포커스를 그대로 사용합니다.

- `paper-panel.svg`: 비대칭 종이 테두리, 가장자리의 옅은 채색, 종이 질감.
- `brush-coral.svg`, `brush-sage.svg`: 붓으로 칠한 행동 버튼과 메뉴 탭.
- `tape.svg`: 수첩과 대화창에 붙이는 마스킹 테이프.
- `title-sketch.svg`: 타이틀의 종이 표지와 작은 딱지 스케치.
- `paper-planes.svg`, `leaf-sprig.svg`: 대화·장면 전환·메뉴의 여백 삽화.
- `trophy.svg`, `backpack.svg`: 결과창과 빈 가방 삽화.

글꼴은 Jua(본문)와 Gamja Flower(손글씨 제목), 장면 간판은 기존 Galmuri11을 사용합니다.
라이선스는 각각 `assets/fonts/Jua-OFL.txt`, `GamjaFlower-OFL.txt`, `OFL.md`에 보관합니다.
