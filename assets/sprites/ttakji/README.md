# 딱지 스프라이트 45종

45종 × 4상태 = **180개 개별 PNG**. 기존 신문지·색종이·머리카락 12장은 유지하고, 42종 168장을 새로 제작했습니다.

모든 파일은 **256×256 RGBA PNG**이며 실제 투명 배경을 갖습니다. 파일별 중복 해시 없음, 최소 외곽 여백 26px, 종류별 4파일 존재를 확인했습니다. 신규 42종은 4상태 비교표와 48px 인벤토리 샘플로 육안 검토했습니다.

- `base`: 전투용 앞면
- `flipped`: 뒤집힌 뒤의 뒷면. 뒤집히는 중간 애니메이션이 아닙니다.
- `inventory`: 위에서 본 아이템 아이콘
- `damaged`: 같은 앞면에 소재별 손상 표현

파일 규칙: `{slug}/ttakji_{slug}_{state}.png`.
