# 딱지들

> Google Docs 기획서의 「딱지들」 탭을 옮긴 문서입니다. 기획 초안과 예시 수치는 원문에 표시된 상태를 따릅니다.

## 딱지 아이디어 목록

기본 후보와 확장 후보를 구분하고, 확장 후보는 소재와 콘셉트별로 정리.

### 1. 공통 강화 규칙

검토 중인 아이디어

- 강화할수록 겹(LEVEL)이 늘어난다.

- 공격력은 높아지고 방어력은 낮아진다.
