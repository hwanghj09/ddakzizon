# 딱, 지존 — 최소 플레이 가능 버전

> 기준: [Google Drive 기획 문서](https://docs.google.com/document/d/16BvcP8xamM6LgPUgpgfAOyOgZ3CvyKX5z-bTQtgNAAo/edit), 2026-10-29 갱신 내용과 최소 구현 계획.
>
> 이 문서는 구현 목표와 테스트용 제안이다. 저장소의 현재 구현 완료 여부를 조사한 결과가 아니며, 전투 수치와 미정 사항은 확정 기획이 아니다. 실제 작업 전 기존 기능과 비교해 재사용한다.

## 1. 목표와 범위

학교에서 패배한 주인공이 집에서 연습하고 학교 재대결에서 이긴 뒤, 마을을 걸어 주민센터에서 대회에 접수하는 흐름까지 플레이한다. 접수 후 대진표와 버전 완료 안내를 표시한다. 이후 대회 경기는 다음 단계에서 연결한다.

| 순서 | 장소 | 플레이어 행동 | 완료 조건 |
|---|---|---|---|
| 1. 첫 경기 | 운동장 | 민수와 대화하고 타이밍 게이지 사용 | 공격을 경험한 뒤 스토리상 패배 |
| 2. 귀가 | 학교 앞 → 주민센터 앞 → 광장 → 골목 → 집 | 직접 걸어서 이동 | 집에 들어감 |
| 3. 딱지 만들기 | 집 | 식탁에서 신문지 딱지 접기 | 딱지 획득 및 장착 |
| 4. 연습 | 집 | 표적을 향해 공격 | 공격과 게이지 정지를 한 번씩 경험 |
| 5. 재대결 | 운동장 | 민수에게 도전 | 실제 경기에서 승리 |
| 6. 대회 발견 | 학교 앞 | 포스터 조사 | 접수 목표 표시 |
| 7. 대회 접수 | 주민센터 | 접수원과 대화 | 접수 완료 및 대진표 표시 |

첫 경기는 이야기상 패배하는 경기임을 시작 전에 알린다. 재대결은 실제 승패를 적용하며, 지면 **즉시 재도전** 또는 **집 연습**을 선택할 수 있다.

## 2. 구현 우선순위

### 1순위: 처음부터 끝까지 플레이

| 구분 | 목표 | 임시 처리 |
|---|---|---|
| 장면 | 운동장, 학교 앞, 주민센터 앞·로비, 광장, 골목, 집 내부 | 단색 배경과 장소 이름 |
| 이동 | 좌우 이동, 구역 연결, 집 출입, 카메라 | 정지 캐릭터 이미지 이동 |
| 상호작용 | 민수, 식탁, 연습 표적, 포스터, 접수원 | 가까이 가서 버튼 하나로 실행 |
| 대화 | 화자 이름, 대사, 다음 버튼 | 초상화 없이 텍스트 |
| 전투 | 공격 → 게이지 정지 → 피해 → 뒤집기 판정 → 상대 턴 | 흔들림과 효과음으로 타격 표현 |
| 스토리 | 첫 패배 → 제작 → 연습 → 재대결 승리 → 포스터 → 접수 | 진행 단계에 따라 목표·대사 변경 |
| 결과 | 승패, 재도전, 접수 완료 | 결과 문구와 버튼 |
| 저장 | 주요 사건 완료 직후 자동 저장 | 브라우저 localStorage |

**완료 기준:** 새 게임에서 직접 이동하고 접수 완료 화면까지 도달한다.

### 2순위: 이해와 조작 편의

- 현재 목표, 진행 방향 화살표와 장소 이름 표시
- 첫 이동·상호작용·공격 시 조작 안내
- 딱지 흔들림·뒤집힘, 타격 효과와 판정 문구
- 연습 판정 및 재시도 버튼
- 신문지 딱지의 인벤토리와 장착 상태
- 대화 건너뛰기, 소리 설정, 이어하기
- 모바일 터치 조작과 화면 크기에 맞는 UI

### 3순위: 접수 이후 확장

| 기능 | 추가 시점 |
|---|---|
| 마을 대회 1회전과 보상 | 접수 흐름과 경기 재미를 확인한 뒤 |
| 상점과 재화 | 재료와 가격을 정한 뒤 |
| 압축기와 강화 | 1회전 및 강화 수치를 정한 뒤 |
| NPC 추가 대화·마을 장식 | 필수 경로와 진행 상태가 안정된 뒤 |
| 제련·융합 | 기능과 해금 조건을 정한 뒤 |
| 선수 훈련·스킬 | 경기 밸런스와 해금 순서를 정한 뒤 |

## 3. 장면과 상호작용

### 운동장

| 대상 | 행동 | 결과 |
|---|---|---|
| 민수 | 첫 대화 후 경기 | 공격과 타이밍을 경험하고 이야기상 패배 |
| 민수 | 집 연습 후 대화 | 실제 승패가 적용되는 재대결 |
| 민수 | 재대결 승리 후 대화 | 도윤의 이사 소식 전달 |
| 벤치 | 조사 | 짧은 대사. 선택 요소 |

첫 경기는 플레이어가 공격하고 게이지를 멈춘 뒤 민수의 공격으로 패배하는 연출을 임시로 사용한다.

### 집

| 대상 | 행동 | 결과 |
|---|---|---|
| 식탁 | 신문지를 눌러 딱지를 접는다 | 신문지 딱지 획득·자동 장착 |
| 연습 표적 | 타이밍 공격 연습 | 한 번 경험하면 학교로 이동 가능 |
| 문 | 골목으로 나가기 | 구역 전환 |

접기는 버튼 1회와 화면 전환으로 시작하고, 이후 접기 미니게임으로 교체할 수 있다. 연습은 실패해도 반복하거나 끝낼 수 있다.

### 학교 앞과 주민센터

| 장소 | 대상 | 행동 |
|---|---|---|
| 학교 앞 | 대회 포스터 | 재대결 승리 후 조사해 접수 목표 생성 |
| 주민센터 앞 | 입구 | 접수 가능 상태일 때 로비로 이동 |
| 주민센터 로비 | 접수원 | 참가 안내 → 접수 확인 → 대진표 표시 |

### 이동 구역

골목은 집과 광장을, 광장은 골목과 주민센터 앞을, 주민센터 앞은 광장과 학교 앞을, 학교 앞은 주민센터 앞과 운동장을 연결한다. 첫 이동에 방향 화살표를 표시하고 구역 진입 시 장소 이름을 잠깐 보여 준다. 상점과 압축기는 우선 간판으로 표시한다.

## 4. 전투 임시 규칙

아래 수치는 상세 기획의 테스트 제안이며 확정값이 아니다.

1. 양쪽이 딱지 하나씩 사용하고 플레이어가 선공한다.
2. 플레이어와 상대가 번갈아 공격한다.
3. 플레이어는 움직이는 게이지를 멈춘다.
4. 피해 적용 후 뒤집힘을 판정한다.
5. 한쪽 딱지가 뒤집히면 경기가 끝난다.

첫 버전에서는 공격만 사용한다. 스킬 메뉴를 표시한다면 아직 배운 스킬이 없다고 안내한다.

| 항목 | 임시값 | 교체 지점 |
|---|---:|---|
| 신문지 딱지 HP | 100 | 딱지 능력치 데이터 |
| 공격력 | 20 | 딱지 능력치 데이터 |
| 방어력 | 8 | 딱지 능력치 데이터 |
| 안정성 | 10 | 딱지 능력치 데이터 |
| 선수 힘 | 4 | 선수 능력치 데이터 |
| 완벽 | 피해 1.3배 | 타이밍 설정 |
| 좋음 | 피해 1.1배 | 타이밍 설정 |
| 보통 | 피해 1.0배 | 타이밍 설정 |
| 빗나감 | 피해 0.6배 | 타이밍 설정 |

```text
피해 = 최대(1, 반올림((공격력 + 선수 힘 - 상대 방어력 × 0.5) × 타이밍 배율))

뒤집기 확률 = 10% + 60% × (1 - 현재 HP / 최대 HP) - 안정성 × 0.5%p
뒤집기 확률은 5~75%로 제한. HP가 0이면 확률 판정 없이 뒤집힘.
```

상대의 타이밍은 우선 좋음으로 고정하고 이후 난이도에 맞춰 조정한다. 게이지 속도와 각 판정 구간은 표시하고 플레이 테스트로 조정한다.

## 5. UI와 조작

| 우선순위 | 화면 | 필요한 요소 |
|---|---|---|
| 1 | 타이틀 | 새 게임, 이어하기 |
| 1 | 마을 | 목표, 장소 이름, 이동·상호작용 |
| 1 | 대화 | 화자, 대사, 다음 |
| 1 | 경기 | 양쪽 HP, 현재 턴, 공격, 타이밍 게이지 |
| 1 | 경기 결과 | 승패, 재도전 또는 돌아가기 |
| 1 | 접수 | 접수 확인, 대진표, 완료 안내 |
| 2 | 인벤토리 | 신문지 딱지, 이름, 장착 상태 |
| 2 | 설정 | 소리, 조작 안내 |
| 2 | 지도 | 현재 위치와 연결 구역 |

임시 조작은 방향키 또는 A/D 이동, E 상호작용, 스페이스 게이지 정지. 모바일에도 같은 동작의 터치 버튼을 제공한다.

| 우선순위 | 에셋 | 수량·상태 |
|---|---|---|

| 1 | 접수원 | 대기 1개 |
| 1 | 신문지 딱지 | 기본·뒤집힘 각 1개 |
| 1 | 배경 | 운동장, 학교 앞, 주민센터 앞·로비, 광장, 골목, 집 각 1개 |
| 1 | 물체 | 식탁, 표적, 포스터, 접수 책상, 출입문 |
| 1 | UI | 버튼, 대화창, HP 바, 게이지 |
| 2 | 주인공 애니메이션 | 대기·걷기·타격 |

## 7. 미정 사항과 교체 지점

| 미정 사항 | 첫 버전의 임시 규칙 | 나중에 교체할 위치 |
|---|---|---|
| 마을 이름 | `마을`로 표시 | 장소 이름 데이터 |
| 등장인물 이름 | 민수·도윤 사용 | 등장인물·대사 데이터 |
| 경기 수치 | 위의 테스트용 수치와 계산식 | 딱지·선수·전투 규칙 데이터 |
| 상점 가격 | 간판만 표시, 구매 불가 | 상품·가격 데이터 |
| 강화 수치·비용 | 압축기 사용하지 않음 | 강화 단계·비용 데이터 |
| 제련·융합 | 공사 중 간판 | 시설 기능·해금 조건 |
| 딱지 접기 | 버튼을 누르면 획득 | 식탁 상호작용·미니게임 |
| 대진표·상대 | 접수 완료용 임시 대진표 | 대회 참가자·경기 데이터 |
| 이동 거리 | 기획 문서의 좌표를 초기값으로 사용 | 구역 너비·이동 속도 |
| 아트 스타일 | 색상과 글자로 구분한 임시 그림 | 에셋 목록과 이미지 |

수치와 이름은 가능한 한 별도 설정 데이터로 모아 조정하기 쉽게 한다. 기존 구현과 다르면 실제 코드 구조를 확인한 뒤 적용 위치를 정한다.

## 8. 구현 순서와 확인

1. **이동:** 운동장부터 집까지 왕복하고 출입구·카메라를 확인한다.
2. **경기:** 공격부터 승패까지 독립적으로 진행되는지 확인한다.
3. **스토리 연결:** 첫 패배부터 대회 접수까지 상호작용을 이어 붙인다.
4. **저장·재시도:** 사건 완료 후 새로고침해 진행이 유지되는지, 재대결 패배 후 다시 도전할 수 있는지 확인한다.
5. **UI·에셋 정리:** PC와 모바일에서 조작과 화면 겹침을 확인하고 필요한 그림부터 교체한다.

### 완료 점검

- [x] 새 게임에서 접수 완료 화면까지 도달한다.
- [x] 첫 경기는 공격을 경험한 뒤 스토리상 패배한다.
- [x] 연습은 실패해도 다시 하거나 끝낼 수 있다.
- [x] 재대결에서 지면 재도전 또는 집 연습을 선택할 수 있다.
- [x] 포스터와 접수원을 반복해서 눌러도 진행이 중복되지 않는다.
- [x] 새로고침 후 마지막으로 완료한 사건에서 이어진다.
- [x] PC 키보드와 모바일 터치로 필수 조작을 할 수 있다.
