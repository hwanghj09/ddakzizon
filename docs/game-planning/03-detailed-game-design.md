# 상세 게임 기획

> Google Docs 기획서의 「상세 게임 기획」 탭을 옮긴 문서입니다. 기획 초안과 예시 수치는 원문에 표시된 상태를 따릅니다.

# 딱, 지존 — 상세 게임 기획

기존 기획을 바탕으로 만든 구체화 초안. 전투 수치, 보상과 후반 스토리는 플레이 테스트를 위한 제안이며 확정 사항이 아니다.

## 1. 게임 개요

장르: 2D 턴제 딱지 대전·성장 웹게임. 플레이어는 딱지를 만들고 강화하며 선수를 훈련해 더 큰 대회에 도전한다.

핵심 재미: 타이밍을 맞춰 뒤집는 손맛, 딱지와 스킬 조합을 고르는 전략, 평범한 학교 놀이가 세계 대회로 커지는 과장된 성장 이야기.

기본 흐름: 스토리 확인 → 딱지 준비·강화 → 상대 확인 → 경기 → 상금과 보상 획득 → 훈련·제작 → 다음 대회.

## 2. 전투 규칙

확정 방향: 사이드뷰, 플레이어와 상대의 턴제 행동, 공격 시 움직이는 타이밍 게이지, 능력치와 타이밍을 반영한 피해 및 뒤집기 판정.

경기 시작: 양쪽이 사용할 딱지 1개를 선택한다. 주인공이 먼저 행동하며 이후 상대와 번갈아 턴을 진행한다. 한쪽 딱지가 뒤집히면 경기가 끝난다.

내 턴: 공격 또는 사용할 수 있는 스킬을 선택한다. 공격형 행동은 게이지를 멈춘 뒤 타격 애니메이션, 피해 적용, 뒤집기 판정 순서로 진행한다. 상대 턴에도 같은 판정을 적용한다.

타이밍 제안: 완벽 1.3배, 좋음 1.1배, 보통 1.0배, 빗나감 0.6배. 판정 구간과 게이지 속도는 눈에 보이도록 표시하고 테스트 후 조정한다.

능력치 제안: HP는 딱지가 얼마나 버티는지, 공격력은 상대에게 주는 충격, 방어력은 피해 감소, 안정성은 뒤집힘 저항, 정확도는 타이밍 성공 구간에 영향을 준다. 선수의 힘·집중력도 각각 공격과 타이밍에 보너스를 준다.

시작 계산식 제안: 피해 = max(1, 반올림((공격자 공격력 + 선수 힘 − 상대 방어력 × 0.5) × 타이밍 배율)). 상대 HP를 0 미만으로 내리지 않는다.

뒤집기 확률 제안: 10% + 60% × (1 − 현재 HP / 최대 HP) − 안정성 × 0.5%p. 결과는 5~75%로 제한한다. 공격으로 HP가 0이 되면 확률 판정 없이 뒤집힌다. 스킬 보정은 제한 전에 더한다.

예시: 공격력 20, 힘 4, 상대 방어력 8, 좋음 판정이면 피해는 22. 상대 최대 HP 100, 피해 후 HP 48, 안정성 10이면 뒤집기 확률은 약 36%.

경기 종료: 승리 시 상금과 진행 보상을 받는다. 패배 시 재도전하거나 준비 화면으로 돌아갈 수 있다. 튜토리얼 첫 패배는 스토리 연출이며 이후 진행을 막지 않는다.

### 스킬 초안

정밀 타격: 피해 0.8배, 이번 타격의 뒤집기 확률 +15%p. 쿨타임 3번의 자신의 턴.

강타: 피해 1.4배, 타이밍 구간이 좁아짐. 쿨타임 3번의 자신의 턴.

꾹 눌러 펴기: 자신의 HP를 최대 HP의 15% 회복. 공격과 뒤집기 판정은 하지 않음. 경기당 1회.

쿨타임은 사용 후 자신의 턴이 시작될 때 1씩 감소하며 0이면 다시 사용 가능. 첫 스킬은 마을 결승 후 아저씨에게 배운다는 기존 설정을 따른다. 위 스킬과 해금 순서는 제안이다.

## 3. 성장과 경제

딱지 제작: 재료를 얻어 딱지를 접는다. 첫 딱지는 신문지로 시작하며, 새 소재는 스토리·대회 보상 등으로 획득한다. 딱지마다 기본 능력치와 특성이 다르다.

강화: 상금과 재료를 사용해 겹을 늘린다. 공격력이 오르고 방어력이 낮아지는 규칙은 기존 문서의 검토안이므로 테스트 후 확정한다. 강화 전후 능력치와 비용을 보여준다.

선수 훈련: 상금을 사용해 힘 또는 집중력을 높인다. 힘은 공격에, 집중력은 타이밍 구간에 영향을 준다. 각 훈련의 비용과 예상 변화를 표시한다.

시설 구상: 압축기는 강화, 제련소는 소재 가공, 융합기는 서로 다른 딱지의 조합을 담당한다. 제련·융합의 세부 규칙과 해금 시점은 미정이다.

초기 밸런스 예시: 신문지 딱지 HP 100 / 공격 20 / 방어 8 / 안정성 10, 선수 힘 4. 첫 연습 경기 보상 50, 첫 강화 비용 30으로 시작해 실제 플레이에 맞춰 조정한다. 숫자는 확정값이 아니다.

## 4. 스토리와 진행

도입: 초등학교 3학년 주인공이 또래 무리의 부하와 대결한다. 플레이어가 공격과 타이밍을 경험하지만 스토리상 패배하고 딱지를 잃는다. “그날 뒤집힌 건 내 딱지가 아니라 인생이다.”

연습: 집에서 신문지를 접고 타이밍 게이지로 공격을 연습한다. 실패해도 연습을 반복할 수 있다. 학교로 돌아가 부하와 재대결해 이기면 튜토리얼이 끝난다.

대장과의 미완의 승부: 무리의 대장이 이사하면서 대결하지 못한다. 주인공은 대회 광고를 보고 출전을 결심한다.

마을 대회: 앞집 아저씨, 유치원 친구 등을 만나고 결승에서 탈모 아저씨와 대결한다. 승리 후 아저씨가 조언을 전하며 스킬과 머리카락 딱지를 준다.

이후 전개 제안: 지역 경기에서 과거 무리의 대장과 재회한다. 대장은 “너 한번 세계를 뒤집어보지 않을래”라고 말한다. 시·도·전국·대륙·세계·행성으로 무대를 넓히며 각 단계의 상대와 구체적인 이야기는 추후 정한다. 기존 대회 단계와 지역구의 정확한 관계는 확정이 필요하다.

## 5. 화면과 조작

타이틀: 새 게임, 이어하기, 설정. 저장 데이터가 없으면 이어하기 비활성화.

마을/준비 화면: 현재 목표, 보유 상금, 대회장·훈련장·강화 시설·인벤토리 이동 버튼.

인벤토리: 딱지 목록과 이미지, HP·공격력·방어력·안정성, 특성, 장착 버튼. 선택한 딱지를 경기에서 사용한다.

경기 화면: 양 선수와 딱지, 양쪽 HP, 현재 턴, 공격·스킬 버튼, 타이밍 게이지와 판정 결과. 모바일 터치와 PC 클릭을 모두 지원한다.

결과 화면: 승패, 획득 보상, 다음 진행 또는 재도전 버튼. 설정 화면에는 소리와 텍스트 속도 조절을 둔다.

## 6. 필요한 이미지와 소리

우선 제작: 신문지 딱지 기본·뒤집힘·인벤토리·손상 이미지, 주인공과 첫 상대의 기본·타격·피격 애니메이션, 학교 배경, HP·게이지·버튼 UI, 타격·뒤집힘 효과음.

이후 제작: 집과 마을 배경, 대회 상대, 강화 시설, 여러 종류의 딱지와 스킬 효과, 승리·패배 연출. 스프라이트 크기와 프레임 수는 실제 화면과 아트 스타일을 정한 뒤 확정한다.

## 7. 첫 구현 범위

1단계: 학교 첫 패배 → 집에서 신문지 접기·공격 연습 → 학교 재대결을 플레이할 수 있게 만든다. 신문지 딱지 1종, 상대 1명, 기본 공격, 타이밍 게이지, HP·뒤집기 판정, 결과 화면을 포함한다.

2단계: 저장·이어하기, 인벤토리, 상금, 딱지 강화, 선수 훈련을 추가한다. 3단계: 마을 대회와 결승 보상, 스킬을 추가한다. 이후 상위 대회와 딱지 종류를 확장한다.

## 8. 결정할 사항

첫 경기의 패배 연출 방식, 타이밍 구간과 피해·확률 수치, 강화 시 방어력 감소 여부, 스킬별 해금 시점, 딱지 소재별 특성, 대회 단계와 지역구의 관계, 행성 이후 대회 명칭을 플레이 테스트와 함께 결정한다.
