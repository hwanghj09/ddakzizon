# 게임 기획

> Google Docs 기획서의 「게임 기획」 탭을 옮긴 문서입니다. 기획 초안과 예시 수치는 원문에 표시된 상태를 따릅니다.

## 딱, 지존

2D 웹게임 기획 정리

### 1. 게임 개요

핵심 주제　딱지와 선수를 강화하고 대회에 출전해, 세계 제패를 목표로 성장하는 게임.

기본 흐름　훈련·강화 → 대회 출전 → 상금 획득 → 재투자·강화 → 상위 대회 도전

### 2. 성장과 강화

- 딱지 강화: 딱지를 납작하게 만드는 등 다양한 방식으로 강화한다.

- 선수 강화: 주인공의 실력도 함께 성장시킨다.

- 성장 재원: 대회에서 얻은 상금으로 다시 강화한다.

강화 시설 아이디어

- 딱지 압축기

- 딱지 제련소

- 딱지 융합기

### 3. 대회 진행 단계

마을 → 시 → 도 → 전국 → 대륙 → 세계 → 행성 → ????

미정: 행성 이후의 대회 규모와 명칭.

### 4. 경기 방식과 연출

- 기본 시점: 사이드뷰.

- 타격 연출: 딱지를 치는 순간 애니메이션을 재생한다.

전투 방식(확정): C 방식 + A 방식

기본 구조: 플레이어와 상대가 번갈아 행동하는 턴제 전략 전투.

행동 선택: 자신의 턴에 공격 또는 스킬을 선택한다.

타이밍 조작: 공격할 때 움직이는 게이지를 멈추며, 정확도에 따라 공격 효과가 달라진다.

결과 판정: 딱지·선수 능력치와 타이밍 결과를 반영해 피해량과 뒤집기 여부를 결정한다.

연출: 판정 결과에 따라 사이드뷰 타격·뒤집기 애니메이션을 재생한다.

추후 확정: 스킬 종류, 타이밍별 보정 수치, HP와 뒤집기 확률의 구체적인 계산식.

검토 중인 경기 규칙

- HP가 감소할수록 뒤집힐 확률이 증가한다.

- HP가 감소할수록 공격력도 감소하는 방향을 검토한다.

### 5. 설정과 스토리

#### 5.1 도입 — 초등학교 3학년

주인공은 초등학교 3학년 때 딱지치기에서 패배한다. 억울함을 느끼고, 잃은 딱지를 되찾기 위해 접는 법부터 치는 법까지 연습한다.

“그날 뒤집힌 건 내 딱지가 아니라 인생이다..”

#### 5.2 튜토리얼 — 패배, 연습, 재도전

- 또래 무리의 부하들에게 패배한다.

- 딱지 접기와 치기를 연습한다.

- 학교에서 다시 대결해 승리하고 자신감을 얻는다.

튜토리얼 종료 지점: 연습 후 학교에서의 재대결.

무리의 대장은 이사해 버려, 주인공은 대장과의 딱지 승부를 끝내지 못한다.

승리로 자신감을 얻은 주인공은 대회 광고를 보고 출전을 결심한다.

마을

앞 집 아저씨, 유치원 친구, 탈모 아저씨

마을 결승에서 탈모 아저씨를 만나고, 아저씨가 져. 너라도 도대회에서 잘해라 하면서 꿀팁전수(스킬 잠금 해제) 및 머리카락 딱지 지급

지역구에서 과거 무리의 대장을 다시 만난다.

대장: “너 한번 세계를 뒤집어보지 않을래”

### 6. 추후 작성할 항목

- 게임 개요 상세: 주인공의 목표와 전체 여정 구체화.

- 게임 스토리: 이후 전개 작성.

- 필요한 스프라이트: 목록 작성.

- 게임 UI: 화면 구성 작성.

딱지 종류와 개별 아이디어는 「딱지들」 탭에 정리.
