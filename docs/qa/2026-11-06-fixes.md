# 엔딩 플레이 점검 후 수정

[원래 점검 기록](2026-11-06-ending-playtest.md)의 지적 사항과 앞선 게임 흐름 요청을 반영했다. 원래 실플레이의 대사·저장·이미지 증거는 당시 버전의 기록으로 보존한다.

## 수정한 동작

| 항목 | 수정 |
| --- | --- |
| QA-01 | 연습 완료의 ‘학교로 가기’가 실제 운동장으로 이동한다. |
| QA-02 | 이야기 보상은 실제 증가한 훈련 수치를 표시한다. 성장 한도에서는 결과와 과제 안내에 ‘한도 도달’을 표시한다. |
| QA-03 | 아빠와의 아침 당번 약속을 ‘지는 사람이’로 맞췄다. |
| QA-04 | ‘그날의 나’의 몸과 대화 초상화를 주인공으로 연결했다. 민수의 기존 스프라이트 연결은 유지한다. |
| QA-05 | 준비·이야기·제련 화면의 초기 선택과 방향키 선택이 스크롤 영역 안에 나타나도록 했다. |

첫 패배와 집 튜토리얼:

- 짧은 공방 뒤 서로 내구 12가 남은 마지막 한 수를 플레이한다. 딱지가 거의 넘어갔다가 버티고, 민수의 반격에 한 끗 차이로 뒤집힌다. 일반 경기의 피해·뒤집기 확률 공식은 유지한다.
- 패배 대사 뒤 페이드로 집에 도착한다. 아빠 NPC와 대화하며 강화 효과를 배우고 신문지를 접는다.
- 정확한 순서로 접으면 한 번에 성공한다. 실제로 순서를 틀린 경우만 다시 접으며, 두 번째 시도는 끝까지 진행할 수 있다.
- 첫 접기 완료 시 무료 강화 +1을 한 번만 적용한다. 공격 23·내구 110·방어 7이며, 재접속·다시 접기로 +2가 되지 않는다. 기존 +1 저장도 +1로 유지한다.
- 과거 버전에서 패배 뒤 운동장에 남아 있던 저장은 이어서 할 때 집 수업으로 연결한다. 이미 진행한 대회와 엔딩 저장에는 수업을 끼워 넣지 않는다.
- 실제 약한 타격일 때만 양말 연출을 사용한다. PERFECT 등 정상 타격은 표적에 맞은 판정 그대로 보여 준다.

추가 안내·아트:

- 18종 캐릭터의 72개 프레임을 네이티브 32×32로 다시 생성했다. 화면 크기와 발 위치는 유지하며 배경·파노라마는 그대로다.
- 다섯 번 모두 잘 친 상황에서도 실수했다고 말하던 고정 대사를 성적과 충돌하지 않는 대사로 바꿨다.
- 패배 결과에 상대 기술·뒤집힘·남은 내구를 남긴다. 내구가 남아도 뒤집히면 패배한다는 설명을 함께 표시한다.
- 0.6배 피해를 주는 BAD/MISS의 표시 이름을 ‘약한 타격’으로 바꿨다. 전체 이야기와 짧은 체험판의 피해 계산은 유지한다.
- 아빠 이야기 완료 뒤 가족사진, 첫 딱지 반환 뒤·엔딩 뒤 벤치의 조사 문구를 갱신했다.
- PC 화면의 가상 터치 이동 버튼과 관련 입력·스타일을 제거했다. 이동은 A/D·좌우 방향키, 상호작용은 E/스페이스를 사용한다.

## 검증

- `npm run check` 통과.
- `npm test` 단위 테스트 **84개 통과**. 72개 프레임의 32×32 크기·발 위치·투명도·팔레트·고유 프레임도 확인한다.
- `npm run test:browser` 브라우저 검사 **23종 모두 통과**. 이야기 과제 42개와 대회 경기 21개, 엔딩 양쪽 결과·재접속·다시 보기, 짧은 체험판, 아트·배경·스크롤·오디오·PC 조작을 포함한다.
- 새 `tests/qa-fixes.browser.cjs`에서 XP 한도·재접속, 1280×720/1024×600 초기 및 방향키 포커스, 과거 주인공의 몸·초상화, 내구가 남은 패배의 원인 표시, 완료 저장 호환성을 검사한다.
- `tests/school.browser.cjs`에서 새 교실부터 접전·귀가·아빠 수업·접기·연습·학교 재대결까지 검증했다. 마지막 보상 문구 보완 뒤 이 검사를 다시 통과했다.
- 캐릭터 생성 코드로 다시 렌더한 72개 프레임과 내보낸 PNG가 바이트 단위로 일치한다.
